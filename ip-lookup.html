Who owns that IP address?

Drop in a screenshot of a domain and IP list. This page reads it and shows the ASN, ISP and owner of every address, and which ones sit inside a local ISP.

How to use it

  1. 1Add a screenshotDrag it onto the box, press Ctrl+V to paste it, or click the box to browse. No screenshot? Press Try an example.
  2. 2Check the textThe page reads your image, fills the box below and starts the lookup. If a digit looks wrong, fix it and press Look up owners again.
  3. 3Read the resultsEach IP gets an owner, an ISP and a color tag. Filter, search or download the table.

One domain and one IP address per line. Edit it if anything looks wrong, or type your own list here.

    What the colors mean

    CDN or cloud
    The IP belongs to a content delivery network, a cloud company or the service itself, such as Akamai, Fastly, Google or ByteDance.
    Local ISP
    The IP belongs to an internet provider in Nepal, such as Ncell, WorldLink, Subisu, Websurfer or Nepal Telecom. For a big site like TikTok, this usually means a cache server placed inside that ISP.
    Other
    Any other network.
    Lookup failed
    The owner could not be found. Check the IP in the text box, then press Look up owners again.

    Tips for a clean read

    • Crop to the table. Keep only the domain and IP columns, with no extra windows around them.
    • Capture at 100% zoom or larger. Small, blurry text is the most common cause of a misread digit.
    • Keep each IP whole. If the edge of the screenshot cuts an address off, the page will look up a different one.
    • Always check the text box. It takes ten seconds and catches almost every mistake.

    Questions

    Is my screenshot uploaded anywhere?

    No. The image is read inside your browser and never leaves your device. Only the IP addresses are sent to the free ipwho.is service to find their owners.

    Why is a domain name spelled slightly wrong?

    Reading text from an image is not perfect. A name like mcs-sg can come out as mes-sg. The lookup uses the IP address, so the owner is still correct. Fix the name in the text box if you want it tidy.

    Can I use a text list instead of an image?

    Yes. Type or paste lines like www.tiktok.com 23.57.75.160 into the text box and press Look up owners. IPv4 and IPv6 both work.

    What does "Hosted inside" mean in the notes?

    It means the IP belongs to a local ISP, but the domain belongs to someone else. Big sites place cache servers inside ISP networks so videos and pages load faster.

    How accurate are the owner names?

    They come from public registry data, which is good for who runs a network but can lag behind recent changes. Treat it as a strong hint, and confirm with a whois lookup if it matters.

    Can I run it on my own computer?

    Yes. The same project includes a command-line version. See the GitHub page for setup steps.
